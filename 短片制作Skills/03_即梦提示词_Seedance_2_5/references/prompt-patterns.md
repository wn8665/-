## Universal prompt

```text
[时长]，[比例]，[画面类型与整体风格]。

参考素材：
@图片1用于[身份/服装/产品/场景/首帧]；
@视频1用于[运镜/动作/节奏/创意结构]；
@音频1用于[音色/对白/音乐节奏]。

[主体]在[地点]完成[核心事件]，[整体情绪与叙事目标]。

全局设定：
[角色、场景、光影、镜头、连续性规则]。

[时间轴或连续故事线]

声音：
[对白、旁白、环境音、音效、音乐要求]。

全程保持：
[身份、服装、产品结构、场景布局、色调等]。
不出现：
[具体排除项]。
```

Omit unused sections instead of filling them with generic words.

## Text-only generation

```text
15秒，9:16竖屏，写实电影短片，雨夜高对比霓虹光。
一名穿红色防水风衣的年轻女快递员骑车穿过狭窄老城区，为一位独居老人送上生日蛋糕。
0–4秒：低机位跟拍自行车冲过积水，水花掠过镜头，女快递员抬头确认门牌；
4–9秒：手持近景跟随她抱着蛋糕跑上昏暗楼梯，呼吸急促，楼道感应灯依次亮起；
9–13秒：门打开，暖黄灯光照到她湿润的脸和老人惊讶的表情，她笑着说“祝您生日快乐”；
13–15秒：镜头缓慢拉远，门内暖光与门外蓝色雨夜形成冷暖对比。
环境音包含雨声、轮胎压水声、脚步和轻微喘息；不出现字幕、水印或额外人物。
```

## Multimodal character scene

```text
20秒，16:9，克制的现实主义电影风格。
@图片1作为林夏的脸部、短发和深绿色夹克参考；
@图片2作为周远的脸部、灰色大衣和黑框眼镜参考；
@图片3作为深夜便利店场景与冷白荧光灯参考；
参考@视频1缓慢横移后推近的运镜节奏。

林夏与周远隔着便利店货架重逢，先认出对方但都没有立刻开口。
0–6秒：镜头沿货架横移，林夏在画面左侧停下，周远从右侧背景进入；
6–13秒：焦点从前景商品转到两人眼神，保持两人各自脸部和服装特征；
13–18秒：周远轻声说“好久不见”，林夏短暂吸气后点头；
18–20秒：镜头推近林夏含泪但克制的眼神。
两人身份、服装和左右位置不混淆；不新增顾客，不出现字幕。
```

## Native 30-second video

```text
《最后一班渡船》，30秒，2.35:1，24fps，写实东方电影感。

多模态参考：
@图片1作为女主的脸部、低盘发和素白交领服装参考；
@图片2作为清晨江岸、木码头与薄雾参考；
@音频1作为女主低声、克制、微微哽咽的音色参考。

全局设定：
清晨江边，冷灰蓝色自然光，远处一艘小船若隐若现；始终采用站在女主对面的主观视角，
近景与特写为主，浅景深，一镜到底，镜头呼吸感轻微，人物身份与服装不变。

0–6秒：女主低头整理手中的旧信，江风吹动鬓边碎发，背景只有水声和远处船桨声；
6–13秒：她抬眼望向镜头，眼神犹豫，轻声说“这封信，你还是带走吧”；
13–20秒：镜头缓慢靠近，她把信递向镜头，手指轻微发抖，眼眶湿润但没有落泪；
20–26秒：远处船夫鸣笛，她短暂回头，再看向镜头，勉强微笑；
26–30秒：她松开信，转身走向薄雾中的渡船，镜头停在原地目送，不切镜。

全程保持自然皮肤纹理、真实衣料与微表情，不出现现代物件、字幕、Logo、水印或额外BGM。
```

## Ultra-long video

For 30–180 seconds, use scene blocks:

```text
生成一段[总时长]的超长视频，[比例]，[整体类型、受众与情绪]。

参考素材：
[逐项映射]

全局规则：
- [角色身份、服装和产品一致性]
- [时代、地点、时间、光线和色彩]
- [摄影语法和声音策略]
- [禁止项]

场景一（0–[时间]）：[地点、目标、关键动作、镜头、声音、结束状态]
转场：[共同物体/动作/光线/声音作为视觉锚点]

场景二（[时间]–[时间]）：[内容]
转场：[内容]

场景N（[时间]–[总时长]）：[内容与收束]
```

Keep transitions explicit. Repeat identity or wardrobe only when a scene transition risks ambiguity.

## Video extension

### Backward extension

```text
将@视频1向后延长10秒。
从原视频最后一帧[边界状态]自然续写，保持[人物、服装、动作方向、镜头、天气、光线、声音]一致。
0–4秒：[新动作一]；
4–8秒：[新动作二]；
8–10秒：[收束状态]。
新增部分不切换地点，不改变人物身份，不出现字幕、水印或新道具。
```

### Forward extension

```text
将@视频1向前延长8秒。
新增内容的最后一帧必须自然衔接到原视频第一帧的[边界状态]，
保持相同的[场景、时间、服装、镜头焦段和运动方向]。
0–3秒：[前置事件]；
3–8秒：[动作推进到原视频开场状态]。
```

## Smart or advanced edit

```text
编辑@视频1。
在00:05–00:14，将箭头所指的银色手提包替换为@图片1中的深棕色皮革手提包，
保留@图片1的包型、金属扣和皮革纹理。
替换后的包随人物手部动作自然摆动，遮挡、透视和光影与原视频一致。
保持人物脸部、服装、动作、原有运镜、背景、其他物品和声音完全不变；
手提包在所有出现帧中保持同一尺寸与外观。
```

For removal:

```text
在00:03–00:09，移除框选区域内的路牌，用周围连续的砖墙纹理自然补全。
保持相机运动、墙面光影、行人及其遮挡关系不变。
```

## White-model control

```text
参考@视频1白模的全部镜头轨迹、角色站位、运动路径、动作节奏与时长。
将白模角色A映射为@图片1中的女剑客，保留脸部、发型、蓝色长袍和银色佩剑；
将白模角色B映射为@图片2中的黑甲武士，保留面甲与盔甲结构；
将白模场景替换为@图片3的雪山古寺，保持白模中的台阶、门廊和两人距离关系。

0–6秒：[按白模动作描述映射后的表演]；
6–13秒：[动作与机位]；
13–20秒：[收束]。

只参考白模的空间、动作、构图和镜头，不保留白模材质；
最终使用写实电影质感、冷色自然光，人物身份、武器和服装全程一致。
```

## Specialized patterns

### Product advertisement

```text
@图片1作为产品正面、Logo位置与包装结构参考，
@图片2作为产品侧面和材质细节参考。
15秒高端产品广告，黑色镜面台面，冷白轮廓光。
0–4秒：微距镜头沿包装边缘滑动，展示材质和压印细节；
4–9秒：产品缓慢旋转一周，镜头同步环绕，结构和Logo不变形；
9–13秒：水珠与冷雾从底部扩散，产品停在三分之二侧面英雄角度；
13–15秒：镜头轻推至正面定格。
不新增文案，不改变包装、颜色、Logo和比例。
```

### Dialogue scene

```text
画面（0–6秒）：[景别、人物动作、表情、运镜]
台词（角色A，压低声音、急促）：“[台词]”
画面（6–12秒）：[反应与空间关系]
台词（角色B，平静但坚定）：“[台词]”
画面（12–15秒）：[视觉收束]
声音：[环境音与必要音效]；不自动添加字幕。
```

### One-take camera

```text
一镜到底，全程无切镜。
镜头从[起点]以[运动方式]跟随[主体]，经过[空间节点1]，
利用[前景遮挡/门框/转身]自然调整机位，再进入[空间节点2]，
最终停在[结束构图]。保持运动方向、空间布局、光线连续和主体身份一致。
```

### Remove BGM, retain speech

```text
编辑@视频1，移除整段视频的背景音乐，只保留所有人物对白和真实环境音。
保持原有字幕、画面、剪辑、音量相对关系和口型不变；
不要新增音乐、音效或旁白。
```

### Change viewpoint

```text
编辑@视频1，将原有平视第三人称镜头改为低机位仰拍并缓慢环绕主体半周。
合理补全原视频未展示的地面和背景空间，保持主体动作时序、身份、服装、
场景结构、光线方向和声音不变，透视与遮挡符合真实摄影逻辑。
```

### Green screen

```text
生成@图片1中的人物表演，纯净均匀的绿色背景，人物全身始终完整入镜。
边缘清晰，无绿色溢色，无背景物体，无文字；保留自然衣料和发丝运动。
[允许/不允许]脚下接触阴影，固定镜头，[动作描述]。
```

### Multi-panel storyboard

```text
按@图片1九宫格分镜从左到右、从上到下的顺序生成30秒连贯视频。
每格依次对应[时间段]；严格参考各格构图、景别、人物站位和动作方向，
在相邻分镜之间补全自然动作与转场。角色形象参考@图片2，场景参考@图片3。
```

## Compact camera vocabulary

| Need | Useful terms |
| --- | --- |
| Shot size | 大远景、全景、中景、近景、特写、大特写 |
| Movement | 推、拉、摇、移、跟拍、环绕、升降、航拍、手持、甩镜 |
| Viewpoint | 平视、俯拍、仰拍、低机位、鸟瞰、第一人称、主观视角 |
| Focus | 浅景深、深景深、焦点转移、选择性对焦、背景虚化 |
| Rhythm | 长镜头、慢动作、快切、硬切、卡点、延时、一镜到底 |
| Transition | 遮挡转场、匹配剪辑、甩镜转场、光闪转场、声音桥 |

Choose only the terms that support the story. Camera vocabulary is a control system, not decoration.
